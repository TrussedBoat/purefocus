# PureFocus

A browser extension that blocks distracting sites, short-video sections, and YouTube recommendations. Works with Chrome, Edge, Brave, and Firefox 121+; plain JavaScript with no build step or runtime dependencies.

See [installation, controls, and testing instructions](extension/README.md). Development guidance and the current implementation context are in [CLAUDE.md](CLAUDE.md).

The YouTube recommendation feature is under local validation on `feature/youtube-recommendation-blocking`. The manifest and existing signed package remain at `0.2.0`; no new feature release has been packaged or signed. See the extension README for validation still needed before releasing.
